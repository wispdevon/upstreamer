# Upstream design contract

Reference: `docs/design/concept.png` and the supplied screenshot. Preserve the calm editorial composition, while using the approved lesson titles and accurate contribution language rather than image-generated copy.

- Palette: use the supplied swatches: charcoal #313233 and #504f4e for text, coral #ff7755 for primary actions, sand #c7a782 for warm surface tints, slate #54717d / sky #51b5e0 for diagram accents, and leaf #5e8f72 for the contribution node. Retain warm paper #f8f7f3 for readable negative space. Use charcoal text on bright coral and amber buttons; reserve lighter tints for dark-mode text. Dark surfaces use #313233, #383a39, and #464849. Verify every text/surface pair for AA contrast.
- Type: Georgia for editorial headings and quotations; system sans-serif for navigation, forms, and body. Fluid hero 42–68px, with the diagram stacking before its column becomes cramped; body 16–18px, line-height 1.6.
- Shell: the logo, all five pill navigation links, and theme control share a single comfortable desktop row. Allow wrapping on smaller screens and a two-column phone navigation so all destinations remain visible. Keep keyboard order consistent with the visual flow. Header and page content share the same border-box maximum width and responsive inline padding, so their left and right edges align at all widths. Use generous shell padding and no breadcrumb row beneath the header.
- Start screen: headline and native SVG branch diagram share the desktop hero, followed by two direct path buttons at its bottom: “New to opensource” and “Already building a fork?”. Each button saves its path and opens the first incomplete lesson in that path, or its first lesson when complete. Keep “Draft a pull request” as a quiet link under the headline. Remove the radio card and duplicate start/continue action. On phones stack headline, draft link, diagram, path buttons, five steps, and featured PR. Give sections, list rows, cards, and buttons generous breathing room.
- CSS: Tailwind CSS uses the official Vite plugin with theme and utility layers. Preserve the existing base styles instead of introducing Preflight resets; use utilities for the path action layout and expose the supplied palette through Tailwind theme tokens.
- Lessons: show each answer as a full-width native toggle button with `aria-pressed`, a letter marker, a visible selected check, and a clear focus outline. Keep a separate submit action. Only a correct submission marks the lesson complete and reveals the next-lesson action (or studio after the last lesson). An incorrect submission clears the answer, resets only this lesson’s completion, announces feedback, and returns focus to the first choice. Keep saved completions across reloads. Lesson completion records a learning exercise, not evidence that a real contribution is verified.
- Contribution studio: place the review checklist beside the editable handoff draft on desktop and stack them on smaller screens. Keep checklist inputs native and the draft preview text-only.
- Shared motifs: numbered rules, palette-colored arrows, fine separators, off-white quote panels. No gradients, decorative photos, or fabricated metrics.
- Accessibility: visible focus, skip link, meaningful headings, route focus, native controls, status announcements, reduced-motion support, no horizontal overflow at 360px.
