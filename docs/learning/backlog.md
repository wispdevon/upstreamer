# Learning improvements

These are opportunities to plan, not commitments or claims of implemented behavior. Keep additions tied to observed work; consolidate overlapping ideas.

## Transfer a learning note back into practice

Status: proposed.

Objective: help developers apply one recorded lesson in a second context, rather than treating note-taking as mastery.

Proposed agent task: add an optional practice prompt beside an existing journal note, using its next-practice field as the starting point. Specify a concrete exercise and a way to assess the outcome before changing the app.

Acceptance criteria: a learner can record the exercise, expected observable behavior, and actual outcome; the UI distinguishes proposed practice from completed evidence; existing notes remain unchanged until edited.

Dependencies: collect feedback from using the journal on a real task before choosing the UI or adding storage fields.

Verification: test persistence and export of the chosen representation, keyboard use, and regression protection for existing notes. No implementation or verification has been performed for this follow-up.
